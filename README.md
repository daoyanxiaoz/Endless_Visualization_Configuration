MaaPvz 无尽通用框架可视化配置工具——终极详细 Skill（基于最新版）
一、项目概览
项目名称：MaaPvz 无尽通用框架可视化编辑界面
文件形态：单页 HTML（index.html），所有逻辑、样式、数据定义均内联，无外部依赖
核心目标：为 MaaFramework 的无尽挑战任务生成符合 interface.json 规范的 option 树，通过棋盘拖拽 + 开关联动的方式直观配置《植物大战僵尸2》无尽模式的自定义布阵、补植物、喂豆、抛花、魔甘收尾等复杂操作。
适用场景：玩家或脚本开发者在使用 MaaFramework（基于 MAA 的自动化框架）运行无尽模式时，需要生成自定义布阵 JSON 配置。本工具提供可视化替代手写 JSON 的方式，大幅降低配置门槛。

二、技术架构与依赖
2.1 纯前端架构
HTML5 + CSS3 + 原生 JavaScript (ES6)，无任何第三方库，完全自包含。

数据驱动：currentValues 存储所有选项状态，boardEarly/boardLate 存储棋盘操作数据。

响应式布局：flexbox 适应不同屏幕尺寸。

2.2 核心数据模型
OPTION_DEFS：完整的选项定义树，描述所有可用开关、选择、输入及层级关系。

currentValues：当前所有选项的实际值（switch 的 index，input 的 data，checkbox 的 selected_cases）。

boardEarly/boardLate：二维数组（行×列），每个格子是一个数组，可容纳多个操作项，每个操作项带有 id、type、col、row、slotPos 等属性。

ALL_OPS：所有可布置操作项的静态配置，含 single（单例）、maxCount（最大次数）。

undoStack/redoStack：保存棋盘历史状态，用于撤销/重做。

2.3 数据流
text
用户交互（点击/拖拽/开关）
        ↓
placeOp()/开关事件 → 更新棋盘或 currentValues
        ↓
renderAllBoards() 重绘棋盘
        ↓
updatePreview() → buildFullInstance() 反向生成完整 JSON
        ↓
导出/复制/导入（导入时反向填充 UI）
三、用户界面（UI）详细说明
3.1 整体布局（左-右两栏）
左栏（配置区）：

卡槽备注：8 个输入框，为卡槽添加备注，显示在操作项旁。

布阵操作面板：根据当前 Tab（前期/后期）显示不同操作项列表。支持点击选中+点击棋盘放置、拖拽、键盘 WASD 导航。

快捷开关与批量放置：左侧显示与当前阶段相关的开关（小关喂豆、Boss喂豆、加速、守卫菇启用等）。批量放置开关控制连续放置。

无尽选项树（已默认隐藏）：完整选项层级，可展开/选择，主要用于高级调试。

右栏（棋盘与预览）：

Tab 切换：前期 / 后期，快捷键 A/D。

布阵棋盘：动态网格（列 1~9，行 1~5），显示已布置的操作标签（颜色区分）。右键清空格子，左键放置。

棋盘控制：调整列/行数、重置前期/后期棋盘、设置“前期转后期”关卡数。

右侧快速开关：根据当前 Tab 动态显示：

前期 Tab：只显示“球果切换”控件。

后期 Tab：显示是否抛花、魔甘收尾、小关加速、Boss加速、智能补给、相机神器、使用三叶草、识别魔甘、识别三叶草、识别能量花等常驻开关。

编队切换控件（仅前期显示）：两个独立开关（前期切换编队 / 后期切换编队），勾选后显示编队编号输入框（1~6）。

喂豆间隔动态区域：

前期：当前期棋盘存在 Boss 喂豆操作时显示自定义 Boss 喂豆间隔（秒）。

后期：当后期棋盘存在小关喂豆、Boss喂豆、Boss喂豆2 操作时，分别显示小关间隔（自由输入秒）、Boss间隔（秒）、Boss喂豆2间隔（毫秒）。

预览区：底部只读文本框，实时显示完整 JSON，可一键复制。

工具栏新增按钮：

导入 JSON：选择 .json 文件，自动解析并填充界面（开关、输入、棋盘操作）。

撤销（↩）：撤销上一步棋盘操作，快捷键 Ctrl+Z。

重做（↪）：重做棋盘操作，快捷键 Ctrl+Y 或 Ctrl+Shift+Z。

3.2 交互方式
点击选择操作项：单击左侧操作项选中（边框高亮），再点击棋盘格子放置。批量模式（默认开启）下放置后保持选中。

拖拽放置：从左侧操作项拖拽到棋盘格子。

右键清空：右键棋盘格子清空该格所有操作。

键盘导航：

W/↑、S/↓：移动操作项选择。

A/←、D/→：切换前期/后期 Tab。

Enter/Space：取消当前选中。

撤销/重做快捷键：Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做（焦点不在输入框时生效）。

Tooltip：悬停显示提示，部分重要提示延迟 1000ms。

四、核心功能模块详解
4.1 选项定义系统（OPTION_DEFS）
类型：select、switch、input、checkbox。

层级结构：cases 定义子选项，递归嵌套。

动态生成：卡槽种植、补植物、铲除、守卫菇、铲子等通过循环注入。

最新定义补充：

小关喂豆间隔：由 select 改为 input，字段 seconds，默认 "4"，支持小数。

fw_boss关额外喂豆位置：switch，子项 fw_boss关喂豆2间隔（毫秒）、fw_boss关喂豆2位置（列/行）。

球果相关：frame_wj_custom_球果切换形态、frame_wj_custom_球果位置（select，恐龙/幽灵马/水母），以及补植物中的 frame_球果切换形态、frame_球果位置。

编队切换与自定义 Boss 喂豆间隔已补全。

4.2 棋盘与操作项逻辑
操作项定义：ALL_OPS 包含卡槽、守卫菇、铲子、喂豆、抛花、魔甘等。

放置逻辑 placeOp()：

单例操作自动替换旧实例。

非单例检查 maxCount，自动分配 slotPos。

特殊依赖：feed_ball_late 要求棋盘已存在小关喂豆。

放置成功前调用 saveBoardState() 记录历史。

撤销/重做：saveBoardState 深拷贝棋盘入栈，undoBoard/redoBoard 恢复并重绘。

4.3 导出 JSON 引擎 buildFullInstance()
流程：

备份用户手动控制的开关（防止被棋盘驱动覆盖）。

提取棋盘操作 → rawOps。

重置棋盘驱动开关。

根据 rawOps 填充数据（卡槽、守卫菇、铲子、补植物、喂豆、抛花、魔甘、自定义布阵）。

支持 bossfeed2_late 双 Boss 喂豆。

球果相关不在棋盘上，由开关直接控制。

恢复用户控制的开关。

构建干净 option 树：过滤 index===0 的普通开关，特殊处理识别类反转、喂豆球果坐标、自定义布阵子节点去重。

组装最终实例：包括 CurrentControllerName、Resource、TaskItems 等。

4.4 导入 JSON 反向填充 importFromJSONText()
查找无尽模式节点：在 TaskItems[0].option 数组中查找 name === '无尽模式' 的节点（而不是盲取第一个），兼容含额外顶层选项的官方配置。

重置 currentValues：先调用 initDefaultValues()。

递归填充：遍历无尽模式子选项，根据节点类型写回 currentValues；识别类开关进行索引反转。

重建棋盘：调用 rebuildBoardsFromValues()。关键修复：只导入真正开启（index === 1）的种植/补植物子项，避免默认坐标堆积。

更新 UI：刷新所有面板、棋盘、预览。

重置棋盘尺寸：导入前强制恢复默认 9×5，防止用户之前调整过尺寸导致坐标映射错误（可选）。

4.5 动态显示与阶段区分
右侧快速开关：renderRightPanelSwitches() 根据当前 Tab 决定显示内容：

前期：只显示球果切换。

后期：显示所有常规开关。

喂豆间隔区域：动态检测棋盘操作，显示对应输入框。

编队控件：仅前期 Tab 显示。

4.6 依赖联动与状态同步
识别类开关自动强制父级开启。

放置喂豆球果自动开启小关喂豆、喂豆球果开关并填坐标。

任何开关变化触发 updatePreview() 和 UI 重绘。

五、使用流程与操作指南
5.1 典型配置流程
基本信息：填写配置名称、文件名、控制器、入口任务。

前期配置：

选择前期 Tab。

放置卡槽、守卫菇、铲子、小关喂豆、Boss喂豆等。

若需要球果切换形态，勾选右侧“球果切换”并选择形态。

可设置前期/后期编队切换。

后期配置：

切换后期 Tab。

放置补植物、铲除、小关喂豆、Boss喂豆、Boss喂豆2、抛花、魔甘辅助等。

右侧开关设置抛花、魔甘、加速等。

喂豆间隔自动显示在棋盘下方。

其他设置：前期转后期关卡数。

预览与导出：查看 JSON，导出或复制。

撤销/重做：误操作可随时回退。

导入：可导入之前导出的 JSON 恢复配置。

5.2 高级技巧
批量放置：保持开启可快速连续放置。

键盘操作：WASD 快速选择操作项。

右键清空：快速修正。

小关喂豆间隔支持小数：如 4.5。

Boss 双喂豆：放置两个 Boss 喂豆点，设置不同间隔。

导入/导出：作为配置备份和迁移手段。

6.3 扩展指南
新增操作类型：在 ALL_OPS 添加对象，补充 OPTION_DEFS，修改导出/导入逻辑。

新增开关：在 OPTION_DEFS 定义，加入 SWITCH_GROUPS 或 RIGHT_SWITCHES，必要时添加依赖规则。

新增动态区域：参考 lateFeedIntervals，编写 init/update 函数，并在 renderAllBoards 和 Tab 切换时调用。

七、常见问题与注意事项
导入堆积问题：已修复，仅导入 index===1 的子项。

导入找不到无尽模式：已修复为按名称查找。

撤销/重做：仅记录棋盘操作，不记录开关变化；最多 50 步。

球果切换仅在前期显示：右侧开关按 Tab 区分，设计如此。

小关喂豆间隔自由输入：请尽量输入数字（可含小数点）。

Boss 双喂豆依赖：建议两个 Boss 喂豆点都放置，否则脚本可能异常。

导入坐标超出棋盘范围：会被忽略，导入前确保棋盘尺寸为默认 9×5。

导入导出不包含卡槽备注：备注仅存在于界面，需手动记录。

八、总结
本工具已进化为一款功能完备、贴近官方标准、交互友好的 MaaFramework 无尽模式配置生成器。它支持：

棋盘拖拽布局，覆盖前期/后期全部操作。

小关喂豆间隔自由输入、Boss 双喂豆、球果切换形态等高级功能。

JSON 导入导出，方便配置迁移。

完善的撤销/重做机制。

界面按阶段动态显示，减少干扰。

适合个人玩家和脚本开发者使用，极大降低了无尽模式配置文件的手写门槛。未来可扩展方向：本地存储、多配置管理、配置对比、更多预设模板。
